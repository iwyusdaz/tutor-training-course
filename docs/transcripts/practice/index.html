Spot the move

Practice naming the tutoring moves on ten short exchanges drawn from this site's transcript library. For each exchange you pick (1) which move the tutor used — or which failure mode replaced it — and (2) whether the move worked. Feedback explains the reasoning and links the source transcript.

This is practice, not a test. All exchanges are fictional, constructed for training purposes. Nothing you answer is stored — the tool runs entirely in your browser; there is no server, no account, no analytics. Closing the page forgets everything.

Move names and hint-ladder levels match the shared tutoring-moves vocabulary (Socratic AI Tutor, spec v1.0, 2026-10-25).
