# Alignment table

{: .label .label-purple }
Objective → module → practice → rubric row → fidelity metric. Every row must be fillable; an objective with no metric is decoration, and a metric with no objective is surveillance. Both move-name columns use the shared vocabulary from the [Socratic AI Tutor's pedagogy rules](https://github.com/iwyusdaz/socratic-ai-tutor/blob/main/spec/pedagogy-rules.md) (v1.0, 2026-10-25).

## The empty-row test

If a proposed training objective fills no metric row, it isn't measured — cut it or measure it. If a fidelity metric fills no objective row, it isn't trained — stop collecting it or start training it. This table is how the fictional program keeps [training](/tutor-training-course/modules/), [observation](/tutor-training-course/coaching/observation-rubric.md) and [measurement](measurement-plan.md) one system instead of three documents.
