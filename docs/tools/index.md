# Tutor tools

Four tools tutors use daily. Each maps to a [competency domain](/tutor-training-course/research/competency-model.md) and to a row the [coordinator](/tutor-training-course/coaching/observation-rubric.md) actually checks during observations — tools that nobody reads are decoration, and these are designed to be *the* working documents of the fictional program.

| Tool | Used when | Serves |
|---|---|---|
| [Session plan template](session-plan-template.md) | Before every session (5 min to fill) | Domain 2 · structure |
| [Exit-ticket bank](exit-ticket-bank.md) | Planning (choose 1–2 items) and data review | Domains 3 + 5 · errors and data |
| [Student progress tracker](student-progress-tracker.md) | Same day, after each session (3 min) | Domain 5 · data use (privacy-safe) |
| [Tutor self-reflection form](tutor-self-reflection.md) | Weekly (10 min) · input to coaching | All domains · [coaching cycle](/tutor-training-course/coaching/coaching-cycle.md) |

All tools are print-friendly and privacy-safe: initials only, no student names, no photos of student work, storage per the school's data agreement ([measurement plan §privacy](/tutor-training-course/program/measurement-plan.md)).
